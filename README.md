# SQL Data Analysis Project

This project contains SQL scripts for analyzing employee and department data.  
It demonstrates skills in:

- Table creation
- Data insertion
- Filtering
- Aggregations
- JOIN operations
- Reporting

## Files
- `dataset.sql` — Creates tables and inserts sample data
- `queries.sql` — Contains SQL queries for analysis

## How to Use
1. Open any SQL environment (Oracle, MySQL, SQL Server, SQLite)
2. Run `dataset.sql` to create tables
3. Run `queries.sql` to execute analysis queries

## Example Queries
- Employees who joined after 2020  
- Average salary by department  
- Highest salary employee  
- Employee count per department
